**결론부터: MCP로 Claude를 파일·Obsidian·Craft·GitHub에 연결하면, AI가 내 실제 파일과 문서를 읽고 수정할 수 있다(작업마다 승인). 복사·붙여넣기 왕복이 줄어든다.**

[Model Context Protocol(MCP)](https://modelcontextprotocol.io)은 Anthropic이 2024년 11월 공개한 오픈 프로토콜로, AI 앱이 외부 도구·데이터와 표준 방식으로 연결되게 해 준다. Claude뿐 아니라 여러 AI 앱이 지원한다. 이 글에서는 설정부터 Obsidian·Craft 연동 사례, 커스텀 서버 예제까지 다룬다. 이 연동이 전체 자동화 스택에서 어떤 위치를 차지하는지는 <Link href="/ko/blog/solo-developer-automation-stack">1인 개발자 자동화 스택 10가지</Link>에 정리했다.

## MCP는 무엇이고 왜 중요한가?

MCP 없이 AI 챗봇을 쓰면 자료를 붙여 넣고 결과를 다시 복사해 옮겨야 한다. MCP는 AI 앱과 외부 도구 사이에 표준 연결 통로를 만든다. Claude 가 내 Obsidian vault 의 노트를 읽고, Craft 문서를 생성하고, GitHub 이슈를 만드는 것이 가능해진다.

| 항목 | MCP 없이 | MCP 있으면 |
|---|---|---|
| 파일 읽기 | 복붙으로 전달 | Claude 가 직접 읽기 |
| 문서 생성 | Claude 출력 → 수동 복사 | Claude → Craft 자동 저장 |
| 데이터 검색 | 수동 조회 후 전달 | Claude 가 DB 직접 쿼리 |
| 도구 연동 | 도구마다 따로 API 코딩 | 표준 서버를 설정에 등록 |

## Claude Desktop 에 MCP 추가하는 법

MCP 공식 문서의 [로컬 서버 연결 가이드](https://modelcontextprotocol.io/docs/develop/connect-local-servers) 기준 순서다.

1. [Claude Desktop](https://claude.ai/download)을 설치하고 최신 버전으로 업데이트한다 (macOS·Windows·Linux)
2. Filesystem 서버처럼 Node.js가 필요한 서버를 쓸 경우 Node.js LTS를 설치한다
3. 시스템 메뉴 막대의 Claude 메뉴 → Settings… → Developer 탭 → **Edit Config**
4. `claude_desktop_config.json`에 서버 항목을 추가한다
   - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
5. Claude Desktop을 완전히 종료했다가 다시 실행한다
6. 입력창 왼쪽 아래 "+"(파일·커넥터 추가) → Connectors → Manage connectors에서 서버와 도구 목록을 확인한다

설정 예시:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/you/Documents"
      ]
    }
  }
}
```

`args`의 경로에는 Claude가 접근해도 되는 폴더만 절대 경로로 적는다. 서버는 내 사용자 계정 권한으로 실행되므로 넓은 폴더를 열어 두지 않는 것이 안전하다. 파일 작업은 실행 전에 매번 승인을 요청한다.

## 어떤 MCP 서버부터 연결해야 할까?

| MCP 서버 | 용도 | 비고 |
|---|---|---|
| **Filesystem** | 로컬 파일 읽기·쓰기 | MCP 공식 참조 서버, 입문용 |
| **Obsidian** | vault 노트 검색·편집 | 커뮤니티 서버 여러 종 |
| **Craft** | 문서 생성·블록 편집 | Craft 공식 제공 |
| **GitHub** | 이슈·PR·코드 검색 | GitHub 공식 서버 |
| **Notion** | 페이지·DB 검색·편집 | Notion 공식 서버 |

참조 서버와 커뮤니티 서버 목록은 [github.com/modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)에 모여 있다. 처음이라면 **Filesystem 하나**로 연결·승인 흐름을 익힌 뒤, 자주 쓰는 앱의 공식 서버를 하나씩 더하는 순서를 권한다. 커뮤니티 서버는 코드와 권한 범위를 확인하고 설치하자.

## Obsidian MCP 실전 연동

**Obsidian MCP**는 Claude가 Obsidian vault의 노트를 읽고 수정하도록 해 주는 연결 방식이다. vault도 결국 마크다운 파일 폴더라 Filesystem 서버로도 다룰 수 있고, 검색·메타데이터에 특화된 Obsidian용 서버를 쓸 수도 있다. 방식별 차이는 <Link href="/ko/blog/obsidian-mcp-plugins-best-5">Obsidian MCP 플러그인 추천 BEST 5</Link>에서, Claude Code CLI와 묶는 패턴은 <Link href="/ko/blog/obsidian-claude-code-mcp">Obsidian × Claude Code MCP 연결</Link>에 정리했다.

작성자의 실제 사례: Obsidian vault의 `02. Blog SEO/10. Pipeline/` 폴더에 있는 SEO 카드를 Claude 가 직접 읽고, 상태를 업데이트하고, Dataview 쿼리 결과를 참조한다. <Link href="https://babipanote.com/blog/obsidian-seo-dashboard">Obsidian SEO 관제 시스템 만든 과정</Link>에서 이 대시보드를 어떻게 짰는지 정리했다.

## 커스텀 MCP 서버 작성 맛보기

공식 [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk)(`@modelcontextprotocol/sdk`)나 Python SDK로 직접 서버를 만들 수 있다. 아래는 이름을 받아 인사하는 도구 하나짜리 서버다. `npm i @modelcontextprotocol/sdk zod` 후 `server.mjs`로 저장한다. SDK 1.32.1, Node.js 22에서 도구 목록 조회와 호출까지 실행해 확인했다.

```javascript
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";

const server = new McpServer({ name: "my-custom", version: "1.0.0" });

server.registerTool(
  "greet",
  {
    description: "이름을 받아 인사합니다",
    inputSchema: { name: z.string().describe("인사할 사람 이름") },
  },
  async ({ name }) => ({
    content: [{ type: "text", text: `안녕하세요, ${name}님!` }],
  }),
);

await server.connect(new StdioServerTransport());
```

`claude_desktop_config.json`에 등록하면 Claude Desktop이 이 도구를 호출할 수 있다.

```json
{
  "mcpServers": {
    "my-custom": {
      "command": "node",
      "args": ["/절대/경로/server.mjs"]
    }
  }
}
``` [Apple 단축어 AI 자동화](/ko/blog/apple-shortcuts-ai-automation)에서 HTTP 요청으로 AI API를 부르는 패턴과는 방향이 반대다. 여기서는 AI가 내 코드를 부른다.

## 트러블슈팅

| 증상 | 원인 | 해결 |
|---|---|---|
| 커넥터 목록에 서버가 안 보임 | config 파일 문법 오류 | JSON 검증 (쉼표 누락 등) 후 완전 재시작 |
| 서버 연결 실패 | Node.js 미설치·경로 오류 | [Node.js LTS](https://nodejs.org) 설치, 절대 경로 확인 |
| 파일 접근 거부 | 허용 폴더 밖 경로 | `args`에 폴더 추가 |
| 도구 호출이 조용히 실패 | 서버 실행 오류 | 터미널에서 서버 명령을 직접 실행해 오류 확인 |

로그는 macOS `~/Library/Logs/Claude/mcp*.log`, Windows `%APPDATA%\Claude\logs`에 남는다. `mcp-server-서버이름.log`에 각 서버의 오류 출력이 기록된다.

## 자주 묻는 질문 (FAQ)

### MCP 는 어떤 모델에서 쓰나요?

Claude Desktop과 [Claude Code](https://docs.claude.com/en/docs/claude-code/overview)에서 로컬 MCP 서버를 연결할 수 있고, Claude 웹·앱에서는 원격 MCP 서버를 커넥터로 추가할 수 있습니다. MCP는 오픈 표준이라 Cursor 등 다른 AI 앱도 지원합니다. 내 컴퓨터의 파일을 다루려면 로컬 서버를 쓰는 Desktop·CLI 환경이 맞습니다.

### 직접 MCP 서버를 만들 수 있나요?

가능합니다. 공식 TypeScript·Python SDK가 있고, 위 예제처럼 도구 하나짜리 서버는 수십 줄이면 됩니다. 더 많은 예시는 GitHub [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers) 저장소에서 볼 수 있습니다.

### 보안은 안전한가요?

로컬 서버는 내 컴퓨터에서 내 계정 권한으로 실행되고, 서버가 읽은 내용은 대화의 일부로 AI 모델에 전달됩니다. 그래서 **신뢰할 수 있는 출처의 서버만 설치**하고, Filesystem 서버는 허용 폴더를 최소로 두는 것이 핵심입니다. 원격 서버는 해당 서비스로 데이터가 오가므로 그 서비스의 정책도 확인하세요.

### Cursor 에서도 MCP 가 되나요?

Cursor도 MCP 서버 연결을 지원합니다. MCP는 표준이라 같은 서버를 여러 앱에서 쓸 수 있습니다. 코드 작업 중에 쓰려면 Cursor나 Claude Code, 문서·노트 작업이 중심이면 Claude Desktop에 연결하는 식으로 나누면 됩니다.

### 한 번 설정한 MCP 는 모든 대화에서 쓸 수 있나요?

네. `claude_desktop_config.json`에 등록하면 Claude Desktop을 실행할 때마다 서버가 함께 시작됩니다. 다만 도구를 실행할 때는 승인을 요청하므로, 요청 내용을 확인하고 허용하세요. 대화마다 커넥터를 켜고 끌 수도 있습니다.

## 마무리

MCP는 "AI를 대화창 밖으로 꺼내는 표준"이다. <Link href="/ko/blog/notion-ai-guide">Notion AI</Link> 같은 폐쇄형 통합과 Apple 단축어 API 호출 같은 수동 연동 사이의 자리를 채운다. Claude Desktop 설치 → Filesystem 서버 하나로 시작하는 것이 입문 코스다.
