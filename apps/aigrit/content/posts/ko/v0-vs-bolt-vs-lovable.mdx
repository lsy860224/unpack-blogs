## 한 줄 요약

[v0](https://v0.app)·[Bolt](https://bolt.new)·[Lovable](https://lovable.dev)는 모두 "프롬프트로 웹을 만드는" AI 빌더지만 내놓는 결과물의 성격이 다르다. **v0는 Vercel 생태계의 React/Next.js 화면, Bolt는 브라우저 안에서 바로 도는 풀스택 프로젝트, Lovable은 내장 백엔드(Lovable Cloud)까지 붙은 앱**에 가깝다.

AI 코딩 도구 전반의 지형은 <Link href="/ko/blog/ai-coding-complete-guide-2026">AI 코딩 완벽 가이드 2026</Link> Pillar에서 더 넓게 다룬다.

## v0 vs Bolt vs Lovable — 개요

| 항목 | v0 | Bolt | Lovable |
|------|------|------|---------|
| **제공사** | Vercel | StackBlitz | Lovable |
| **결과물** | React/Next.js 화면·앱 (shadcn/ui 기반) | 풀스택 프로젝트 | 백엔드가 붙은 웹 앱 |
| **실행 환경** | 미리보기 → Vercel 배포 | 브라우저 안에서 실행 (WebContainer) | 클라우드 미리보기·호스팅 |
| **백엔드** | 직접 연결 | 프로젝트 안에서 구성 | 내장 백엔드 Lovable Cloud |
| **코드 내보내기** | GitHub 등 | GitHub·다운로드 | GitHub 동기화 |
| **무료** | 하루 메시지 제한 | 월 100만 토큰 | 하루 빌드 크레딧 제한 |
| **유료 진입** | Plus 사용자당 월 $30 | Pro 월 $18 (연간 결제) | Pro·Business (공식 페이지) |

출처: [v0 요금](https://v0.app/pricing), [Bolt 요금](https://bolt.new/pricing), [Lovable 플랜 문서](https://docs.lovable.dev/introduction/plans-and-credits). 2026년 10월 확인 기준이며, 세 서비스 모두 사용량(크레딧·토큰) 단위로 한도가 정해져 있어 자주 바뀐다.

세 도구 모두 무료로 감을 잡을 수 있다. 차이는 가격보다 **무엇을 내놓느냐**에 있다.

## 결과물의 성격 — 무엇을 받게 되나

- **v0** — shadcn/ui 같은 컴포넌트 라이브러리를 쓰는 React/Next.js 코드를 만든다. 이미 Next.js 프로젝트가 있다면 화면·컴포넌트를 받아 붙이기 좋고, Vercel로 배포하는 흐름이 자연스럽다
- **Bolt** — 브라우저 안에서 패키지 설치와 실행이 바로 일어나는 WebContainer 구조라, "만들면서 바로 돌려 보는" 경험이 강하다. 프론트·백을 한 프로젝트로 빠르게 시험할 때 맞다
- **Lovable** — 로그인·데이터베이스 같은 백엔드를 내장 Lovable Cloud로 붙여, 코드를 직접 다루지 않는 사람도 앱 형태로 완성하기 쉽다

어느 도구든 생성된 코드는 규모가 커질수록 구조 정리가 필요하다. 오래 운영할 서비스라면 GitHub로 코드를 내보내 버전 관리를 시작하고, 이후 수정은 Claude Code나 Cursor 같은 코딩 도구로 이어 가는 흐름이 일반적이다.

## 배포·수정·코드 내보내기

![배포·백엔드·코드 내보내기 관점의 차이](/images/v0-vs-bolt-vs-lovable/02-deploy-export-matrix.png)

| 관점 | v0 | Bolt | Lovable |
|------|------|------|---------|
| 바로 실행해 보기 | 미리보기 | 브라우저 안에서 실행 | 클라우드 미리보기 |
| 백엔드·DB | 직접 연결 | 직접 구성 | Lovable Cloud 내장 |
| 코드 가져가기 | 쉬움 | 쉬움 | GitHub 동기화 |
| 코드를 모르는 사람의 수정 | 보통 | 보통 | 쉬움 |

백엔드를 어떻게 붙이느냐가 결국 완성도를 가른다. 외부 도구를 연결하는 개념은 <Link href="/ko/blog/claude-mcp-guide">Claude MCP 활용법</Link>도 참고가 된다.

## 내 화면으로 직접 비교하는 방법

1. **만들고 싶은 화면 하나를 정한다** — 예: 히어로·기능 3개·가격표·FAQ가 있는 랜딩페이지
2. **같은 지시문을 세 도구에 넣는다**
3. **수정 요청 세 번을 똑같이 해 본다** — 색 바꾸기, 섹션 추가, 문구 교체
4. **코드를 내보내 열어 본다** — 파일 구조가 이해되는지, 내 프로젝트에 붙일 수 있는지
5. **쓴 크레딧·토큰을 확인한다** — 같은 작업에 한도가 얼마나 줄었는지

## 용도별 추천 — 누가 어느 걸 쓰면 되나

같은 "역할 분리" 사고는 <Link href="/ko/blog/claude-code-vs-cursor">Claude Code vs Cursor 비교</Link>에서도 결론이었다.

- **v0가 맞는 사람**: React/Next.js 프로젝트가 이미 있고, 화면·컴포넌트를 빠르게 받아 직접 통합하려는 사람. Vercel로 배포하는 사람
- **Bolt가 맞는 사람**: 프론트+백을 한 번에 돌려 보며 프로토타입을 빠르게 검증하려는 사람
- **Lovable이 맞는 사람**: 코드를 직접 다루지 않고 로그인·DB가 필요한 앱을 끝까지 만들어 보려는 비개발자·기획자

자동화 도구 전반에서 AI 빌더의 자리는 <Link href="/ko/blog/solo-developer-automation-stack">1인 개발자 자동화 스택</Link>에서 정리했다. AI 빌더는 그중 "초안 생성" 단계를 맡는 한 조각이다.

## 결론 — 프론트 코드냐, 브라우저 풀스택이냐, 백엔드 내장이냐

  <Pros>

    - Bolt: 브라우저 안 즉시 실행, 풀스택 프로토타입 속도, 무료 토큰으로 시작
    - Lovable: 내장 백엔드(Lovable Cloud), 코드를 몰라도 앱 형태로 완성
  </Pros>
  <Cons>

  </Cons>

코드 통합이면 v0, 빠른 풀스택 검증이면 Bolt, 비개발자의 완성형 앱이면 Lovable이다. 코딩 에이전트 자체를 비교하려면 <Link href="/ko/blog/github-copilot-vs-claude-code">GitHub Copilot vs Claude Code</Link>가 별도 축을 다룬다 — 웹 빌더가 화면을 찍어 낸다면, 코딩 에이전트는 코드베이스 전체를 다룬다.

## 자주 묻는 질문 (FAQ)

### v0·Bolt·Lovable 중 비개발자에게는 어느 게 맞나요?

코드를 거의 다루지 않는다면 Lovable이 출발점으로 무난합니다. 내장 백엔드인 Lovable Cloud로 로그인·데이터베이스 같은 기능을 붙이기 쉽기 때문입니다. v0는 React 코드를 다룰 줄 알 때, Bolt는 프로젝트 구조를 이해할 때 장점이 커집니다. 무료로 같은 화면을 만들어 보고 정하세요.

### v0로 만든 코드를 내 프로젝트에 그대로 쓸 수 있나요?

같은 스택(React/Next.js, shadcn/ui)을 쓰는 프로젝트라면 붙이기 쉽습니다. 다만 데이터 로직과 API 연결은 내 프로젝트에 맞게 직접 손봐야 하고, 생성된 코드도 검토가 필요합니다. 붙이기 전에 별도 브랜치에서 빌드와 동작을 확인하세요.

### Bolt와 Lovable은 둘 다 풀스택이라는데 차이가 뭔가요?

Bolt는 브라우저 안에서 프로젝트를 바로 실행하는 환경이 강점이라 개발자의 빠른 프로토타이핑에 맞습니다. Lovable은 내장 백엔드를 붙여 비개발자가 앱 형태로 완성하는 데 초점이 있습니다. 코드를 직접 다루며 통제하고 싶으면 Bolt, 자동 연결 편의가 우선이면 Lovable이 맞습니다.

### 가격은 어느 정도 드나요?

2026년 10월 공식 페이지 기준 세 서비스 모두 무료로 시작할 수 있습니다. 유료는 v0 Plus가 사용자당 월 30달러, Bolt Pro가 연간 결제 시 월 18달러이고, Lovable은 Pro·Business 플랜이 있습니다. 세 서비스 모두 크레딧·토큰 단위 한도가 있어 실제 비용은 사용량에 따라 달라집니다.

## 마무리

세 도구는 "프롬프트로 웹을 만든다"는 같은 약속을 하지만 내놓는 물건이 다르다. v0는 프론트엔드 코드, Bolt는 즉시 도는 풀스택 프로토타입, Lovable은 백엔드가 붙은 앱이다. 내가 코드를 직접 다룰 것인지, 백엔드가 필요한지, 완성품을 원하는지로 답이 갈린다. 무료로 같은 화면을 세 번 만들어 본 뒤 정하는 게 가장 확실하다.
