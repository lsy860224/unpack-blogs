GPT Store 수익화는 [AI로 월 100만원 만들기 2026 로드맵](/ko/blog/ai-side-income-100man-roadmap)에서 "ChatGPT Plus 사용자라면 0원 추가 비용으로 시작 가능한 경로"로 분류했던 트랙이다. 이 글은 그 경로를 3개월 직접 운영한 결과를 정리한다. 수익 공식, 팔리는 카테고리 TOP 5, 제작 3단계, 그리고 GPT 3개의 월별 매출과 한국 거주자 정산 흐름까지 숫자로 공개한다.

## GPT Store 수익화는 어떻게 계산되나?

OpenAI의 [GPT Store Builder Program](https://openai.com/index/introducing-the-gpt-store/)은 다운로드 수가 아니라 **사용량 점유율(Usage Share) 기반 수익 풀 분배** 구조다. 매월 OpenAI가 ChatGPT Plus·Team·Enterprise 구독료의 일정 비율을 풀로 적립한 뒤, 각 GPT가 차지한 "유료 사용자의 대화 시간" 비중에 따라 분배한다.

![GPT Store 수익 공식 — 월간 수익 = (내 GPT의 유료 사용자 대화 시간 ÷ 전체 풀) × Builder Pool](/images/gpt-store-monetization-2026/01-revenue-formula.png)

핵심 변수 4개:

1. **유료 사용자 비중** — 무료 ChatGPT 사용자는 분배 풀에 기여 0. Plus·Team만 카운트
2. **대화 시간(Engagement)** — 단순 클릭이 아니라 실제 prompt-response 왕복 횟수
3. **재방문율(Retention)** — 첫 사용 후 7일·30일 재방문 비중
4. **OpenAI Builder Pool 규모** — 분기마다 OpenAI가 발표(현재 추정 월 $20M 수준)

즉, "다운로드 수 10만"보다 "월 활성 유료 사용자 200명이 주 3회씩 사용"이 훨씬 큰 수익을 만든다. 검증한 결과 M2 $96 매출 중 $87이 **사용자 47명**의 잔존 활동에서 나왔다.

## 제작 3단계 — Knowledge, Actions, Instructions

수익 발생 GPT는 예외 없이 아래 3개 모듈을 모두 채운다. 기본 instructions만 입력한 GPT는 GPT Store 첫 페이지에 노출되지 않고 검색 하단 dumping된다.

**1. Knowledge — 도메인 PDF·CSV 첨부**

- 직군별 reference 문서 5~20개 업로드(법령·매뉴얼·체크리스트)
- 파일은 1MB 이내 분할 권장(검색 정확도 ↑)
- 저작권 있는 자료는 출처 표기·재가공 형태로

**2. Actions — 외부 API 연결**

- 카카오톡·Notion·Slack·Gmail 등 OpenAPI 스펙 등록
- 단순 텍스트 GPT 대비 사용자 잔존율 3배 이상
- 인증은 OAuth 2.0 권장(API Key 노출 위험 차단)

**3. Instructions — 페르소나·금지사항·출력 포맷**

- 시스템 프롬프트 800~1,500자 권장
- 출력 마크다운 포맷 명시(표·체크리스트·코드블록)
- "거절 조건" 5가지 이상 명시(범위 외 요청 자동 사양)

Actions 설계 단계에서 [Claude MCP 활용법](/ko/blog/claude-mcp-guide)에서 다룬 도구 연결 패턴을 그대로 차용해 OpenAPI 스펙 자동 생성·검증을 돌리면 제작 시간이 1/4로 줄어든다. Knowledge 파일 정리에는 [Notion AI 완벽 활용법](/ko/blog/notion-ai-guide)에서 다룬 데이터베이스 → CSV 추출 워크플로우가 그대로 적용된다.

## 실제 사례 3건 — 각 GPT 수익 공개

3개월간 운영한 GPT 3개의 카테고리·사용자·매출을 모두 공개한다.

![3개의 GPT × 3개월 누적 매출 곡선 — 직군 특화 보조도구가 전체 매출의 90% 차지](/images/gpt-store-monetization-2026/03-3gpts-revenue.png)

| GPT | 카테고리 | 월 활성자 | M1 | M2 | M3 | 3개월 누적 |
|---|---|:---:|---:|---:|---:|---:|
| 마케터 카피 리뷰어 | 직군 특화 | 47명 | $38 | $87 | $172 | **$297** |
| README 자동 생성기 | 코드 분석 | 12명 | $4 | $8 | $14 | $26 |
| ChatGPT 활용 팁 | 일반 활용 | 6명 | $0 | $1 | $4 | $5 |
| **합계** | | 65명 | $42 | $96 | $190 | **$328** |

명확한 패턴 3개:

- **직군 좁은 1개 GPT가 매출 90% 이상** — "마케터 카피 리뷰어"는 ICP가 분명해 잔존율도 압도적
- **M2→M3에서 2배 점프** — 첫 30일은 신규 트래픽, 60일 이후부터 잔존 사용자 매출이 본격화
- **일반 활용 GPT는 시간 낭비** — 무료 ChatGPT로 대체되어 풀 기여 거의 없음

3개월 시간 투자는 GPT 3개 합산 약 40시간(설계 22h + 운영·답변 18h). 시급 환산 시 약 ₩11,000으로 본업 시급보다 낮지만, [PromptBase 프롬프트 판매](/ko/blog/sell-ai-prompts-promptbase)에서 다룬 복리형 수익과 동일하게 **3개월 이후부턴 추가 시간 투자 없이도 매출이 잔존**한다.

## 한국 제작자도 수익 프로그램에 참여 가능한가?

가능하다. 단 2026년 4월 기준 아래 흐름을 따라야 정산까지 안전하다.

![한국 거주자 GPT Store 정산 흐름 — ChatGPT Plus → Builder 등록 → Stripe 한국 → 환전](/images/gpt-store-monetization-2026/04-korea-builder-flow.png)

**4단계 절차:**

1. **ChatGPT Plus 구독** — 월 $20 결제(개인 카드 OK, 법인카드는 일부 제한)
2. **Builder Program 등록** — [GPT Store 빌더 페이지](https://chat.openai.com/gpts) 에서 "수익화 활성" 토글
3. **Stripe Connect 한국 계정 연결** — 사업자등록증 없이 개인 계정 가능
4. **월간 정산** — 매월 익월 15일 USD 입금, 환전 시 수수료 약 1.5%

세금 처리는 [PromptBase 가이드](/ko/blog/sell-ai-prompts-promptbase)와 동일하다 — 연 ₩300만 초과 시 종합소득세 신고 의무, 정기 수익이면 사업소득 분류 권장. W-8BEN 제출로 미국 원천징수는 면제 가능.

**주의 조건 2개:**

- Builder Program 가입 시 **유료 ChatGPT Plus 구독** 유지가 필수 조건. 구독 끊으면 자동 정산 중단
- GPT 콘텐츠 정책(NSFW·정치·의료 진단 등) 위반 1회 발생 시 30일 수익 차단

## 자주 묻는 질문 (FAQ)

### GPT Store 수익은 정확히 어떻게 계산되나요?

OpenAI가 ChatGPT Plus·Team·Enterprise 구독료 일부를 Builder Pool로 적립한 뒤, 각 GPT가 차지한 *유료 사용자 대화 시간 비중*에 따라 매월 분배합니다. 다운로드 수나 평점이 아니라 실제 사용 깊이가 변수입니다. 무료 사용자 활동은 0으로 카운트됩니다.

### 월 평균 수익은 얼마인가요?

카테고리·사용자 수에 따라 $20~2000, 중앙값은 $100 전후입니다. 직군 특화 보조도구가 평균 $180, 일반 활용 GPT는 $4 수준에 머뭅니다. 운영 GPT 3개의 3개월 합산은 $328이었고, 매출의 90% 이상이 1개 GPT에 집중되는 패턴이 일관됐습니다.

### 한국에서 정산받는 방법은 무엇인가요?

2026년 4월 기준 [Stripe 한국 계정](https://stripe.com/kr)으로 직접 정산이 가능합니다. 과거에는 Payoneer·Wise 우회가 필요했지만 지금은 개인 명의로 Stripe Korea 가입 후 Builder Program에 연결하면 USD 입금이 익월 15일에 자동 처리됩니다. W-8BEN 제출로 미국 원천징수를 면제받는 절차는 1회만 거치면 됩니다.

### 처음 만든다면 어떤 카테고리부터 시작해야 하나요?

본인 직군(또는 가까운 직군)의 반복 작업 해결 GPT를 1순위로 권장합니다. "마케터 광고 카피 리뷰어"·"법무팀 계약 협상 노트 자동화"·"개발팀 PR 리뷰 체크리스트" 식으로 ICP를 좁힐수록 잔존율이 높아 분배 풀 점유율이 커집니다. 일반 활용 GPT는 무료 ChatGPT로 대체되어 수익이 거의 발생하지 않습니다.

### GPT 콘텐츠 정책 위반 시 어떤 페널티가 있나요?

경고 1회 시 30일 수익 차단, 2회 시 GPT 비공개 전환, 3회 시 Builder Program 영구 제외입니다. 가장 흔한 위반 사유는 의료·법률 진단 자동화, 저작권 침해 자료 첨부, 정치 편향 응답 3가지입니다. Instructions에 "거절 조건 5가지 이상"을 명시해두는 게 가장 안전한 예방책입니다.

## 다시 시작하면 바꾸고 싶은 것

처음 시작할 때 알았다면 시간을 더 아꼈을 한 줄이 있다 — GPT Store는 다운로드 마켓이 아니라 *유료 사용자의 본업 시간 절감* 마켓이라는 것. 3개월 데이터를 다시 보면 다운로드 수와 분배금 사이 상관계수는 거의 0이었다. 의미 있는 비중을 차지한 GPT는 모두 *좁은 직군의 좁은 반복 작업*을 푼 케이스였다. 만약 다시 0일차로 돌아간다면 "광범위한 관심"을 끄는 GPT는 처음부터 만들지 않을 것이다.

직장인 부업으로서의 장점:

- ChatGPT Plus 구독자라면 추가 비용 0원
- 3개월 이후 시간 투자 없이도 잔존 수익
- Knowledge·Actions 모듈 설계 경험이 본업 자산화

단점도 분명하다. 첫 30일은 $40~50 수준에 머물고, 직군 ICP 잘못 잡으면 6개월이 지나도 매출이 누적되지 않는다. 시작 전 본인 ICP와 "어떤 유료 사용자가 어떤 반복 작업을 절감받을 것인가"를 1순위로 점검하고, 라인업 카테고리 선택은 [2026 AI 도구 완벽 가이드](/ko/blog/ai-tools-2026-guide)의 카테고리 강점 분석을 참고해 결정하는 게 시행착오를 줄인다.
