**결론부터: 1인 개발자에게 필요한 것은 도구 개수가 아니라 반복 작업을 맡길 자리다. 작성자는 10가지 도구로 그 자리를 채웠고, 월 유지비는 6만 원대다.**

본업, 가족, 사이드 프로젝트를 동시에 돌리는 방법은 하나뿐이다 — 자동화. 반복되는 일을 도구에 맡기고 "생각해야 하는 일"에 시간을 쓴다. 실제로 쓰는 10가지 도구와 비용 구조를 공개한다.

## 1인 개발자가 가장 먼저 자동화해야 할 것은?

답: **반복 3회 이상인 작업**. 매일 하는 일을 먼저 기록하고, 3번 이상 반복되는 것부터 자동화한다.

내 경우는 이랬다:

- 블로그 스크린샷 캡처·저장 → Apple 단축어
- 글 발행 후 색인 요청 → `/publish-post` 스크립트
- 코드 반복 수정 → Claude Code
- Slack·이메일 확인 → Make 시나리오

1주일 동안 매일 하는 일을 메모장에 적어 보고, 3번 이상 반복되는 항목 중 자동화할 수 있는 것부터 하나씩 도구에 맡겼다. 그 결과가 이 스택이다.

## 스택 #1~3 — 일상 업무 자동화

### #1 Apple 단축어

<Link href="/ko/blog/apple-shortcuts-ai-automation">Apple 단축어 AI 자동화 5가지</Link> 글에서 자세히 다뤘다. 핵심은 "블로그캡처" 단축어 — 스크린샷 찍고 AI가 alt 텍스트 생성, 지정 폴더 자동 저장.

| 비용 | 무료 |
|---|---|
| 자동화 범위 | 캡처·번역·요약·캘린더 |
| 난이도 | 낮음 |

iPhone·Mac·iPad에서 같은 단축어를 쓰고, Siri로도 실행할 수 있다. **무료 진입 장벽이 이 스택에서 가장 낮은 도구.**

### #2 Make (구 Integromat)

Slack·Notion·Gmail·Google Sheets를 연결하는 "접착제" 역할. REST·Webhook이 있는 거의 모든 서비스를 잇는다. 공식 사이트는 [make.com](https://www.make.com).

**실전 시나리오 3개:**

1. 블로그 발행 → Slack 채널에 알림
2. Gmail 특정 라벨 → Notion DB 자동 저장
3. Google Sheets 업데이트 → 주간 리포트 메일

| 비용 | 무료 (월 1,000 크레딧) ~ 유료 Core |
|---|---|
| 자동화 범위 | 앱 간 연결 무제한 |
| 난이도 | 중간 |

### #3 Zapier (대안)

[zapier.com](https://zapier.com). 무료 한도는 Make보다 작지만 공식 연동 앱 수가 더 많다. 쓰려는 서비스가 Make에 없다면 Zapier를 확인하자. 둘 중 하나만 쓰면 충분하다.

## 스택 #4~6 — 개발 자동화

### #4 Claude Code

<Link href="/ko/blog/claude-code-vs-cursor">Claude Code vs Cursor 비교</Link>에서 다뤘듯이, 터미널에서 대화하듯 코드를 작성하는 CLI 도구. CLAUDE.md를 읽고 프로젝트 전체 맥락을 파악한 상태에서 작업한다.

**작성자의 사용 패턴:** `/publish-post` 커맨드로 Craft 초안 → MDX 변환 → git push까지 자동화했다. <Link href="https://babipanote.com/blog/building-app-with-claude-code">Flutter 앱을 만든 과정</Link>과 GentleDo App Store 출시까지 이어진 <Link href="https://babipanote.com/blog/building-gentledo-with-claude-code">비개발자 개발기</Link>가 실제 사례다. 도구 전체 흐름은 <Link href="/ko/blog/ai-coding-complete-guide-2026">AI 코딩 완벽 가이드 2026</Link>에 정리했다.

### #5 Cursor

IDE 안에서 AI와 함께 코드 작성. 파일 단위 작업에 강하다. Claude Code와 병행해 **Claude Code=대규모 작업·새 기능 추가, Cursor=소규모 수정·탐색** 용도로 나누면 겹치지 않는다.

### #6 GitHub Actions

CI/CD 자동화. `git push`만 하면 린트·빌드·테스트·배포까지 자동. Vercel과 조합하면 배포 파이프라인이 완성된다.

| 비용 | 퍼블릭 레포 무료, 프라이빗은 월 무료 사용량 제공 |
|---|---|
| 자동화 범위 | 모든 Git 이벤트 |
| 난이도 | 중간 |

## 스택 #7~8 — 지식관리

### #7 Obsidian

SEO 기획·키워드 DB·발행 추적·Dataview 대시보드. 로컬 마크다운이라 Git으로 버전 관리까지 된다. 실제로 어떻게 대시보드를 짰는지는 <Link href="https://babipanote.com/blog/obsidian-seo-dashboard">Obsidian SEO 관제 시스템 만든 과정</Link>에 전부 공개했다. 30분 셋업 가이드는 <Link href="/ko/blog/obsidian-getting-started">Obsidian 시작 가이드</Link>에서, Notion과의 비교는 <Link href="/ko/blog/notion-ai-guide">Notion AI 활용법</Link>과 <Link href="/ko/blog/craft-vs-notion">Craft vs Notion</Link>에서 다뤘다. AI와 vault를 연결하는 방법은 <Link href="/ko/blog/obsidian-mcp-plugins-best-5">Obsidian MCP 플러그인 BEST 5</Link>에 있다.

### #8 Craft

리치 텍스트 글쓰기와 다른 에디터로 옮기기에 편하다. **Obsidian=기획, Craft=글쓰기** 역할 분리가 핵심이다. 작성자의 경우 Craft에서 복사한 서식이 네이버 에디터에서도 비교적 잘 유지돼 네이버 에디션 발행이 단순해졌다. 공식 사이트: [craft.do](https://www.craft.do).

## 스택 #9~10 — 배포·모니터링

### #9 Vercel

[vercel.com](https://vercel.com). `git push` 한 번으로 자동 배포된다. SSL과 CDN이 기본 포함되고, Next.js를 만든 회사라 궁합이 좋다. <Link href="https://babipanote.com/blog/week1-sprint-two-blogs">36시간 스프린트로 블로그 2개 런칭</Link>한 실제 경험에서도 배포 레이어가 가장 편한 부분이었다.

### #10 Google Analytics 4 + Search Console

트래픽 분석 + 검색 성과 추적. 무료. GA4는 GTM 없이 Next.js에 직접 붙여도 된다. GSC 색인 요청·Sitemap 제출까지 1인 블로거 기준 이 두 도구면 충분. 네이버 이중 발행이 필요하면 <Link href="https://babipanote.com/blog/craft-naver-workflow">Craft → 네이버 복붙 워크플로우</Link> 를 추가 스택으로, AdSense 승인 경로는 <Link href="/ko/blog/adsense-approval-prep-checklist">AdSense 승인 셋업 체크리스트</Link>에 따로 정리했다.

## Claude Code + Cursor + ChatGPT Plus — 세 개 다 구독할 가치가 있을까?

월 $60. **세 개 다 쓰는 건 과잉이다.** 기능이 많이 겹치고, 작업 맥락이 세 곳에 흩어지면 오히려 관리가 어려워진다.

**추천 조합:**

- 1인 개발자: Claude Code + Cursor ($40)
- 비개발자: ChatGPT Plus 또는 Claude Pro + Make 무료 ($20)
- 예산 최소: Claude Code만 ($20)

리서치 비중이 크다면 <Link href="/ko/blog/perplexity-ai-guide">Perplexity</Link>를 함께 보자. "생성"은 Claude, "출처가 붙는 검색"은 Perplexity로 나누는 구조다.

처음부터 10개를 전부 세팅하면 배보다 배꼽이 크다. 다음 순서를 권한다:

1. Apple 단축어 (0원, 즉시)
2. Obsidian (0원, 30분 셋업)
3. Claude Code ($20, 터미널 익숙해지면)

5. Cursor ($20, IDE 선호 시)

## 자주 묻는 질문 (FAQ)

### 자동화 시작이 막막한데 뭐부터 해야 하나요?

이번 주 매일 하는 일을 적어 보세요. 3번 이상 반복되는 것 중 가장 짧은 일부터 자동화하면 됩니다. Apple 단축어가 가장 진입 장벽이 낮고, 비용도 들지 않습니다.

### API 키 관리는 어떻게 하나요?

`.env.local` 파일에 저장하고 git에는 올리지 않습니다. 비밀번호 관리자에 백업해 두고, 배포 환경에서는 Vercel 같은 플랫폼의 환경 변수 기능에 등록하면 코드에 키를 넣지 않고도 프로덕션에서 쓸 수 있습니다.

### 월 비용 얼마나 드나요?

작성자 기준 월 6만 원대입니다. 유료는 Claude Pro와 Cursor 두 개이고 나머지는 무료 플랜입니다. Cursor 대신 GitHub Copilot 무료 플랜을 쓰면 더 줄일 수 있습니다.

### Claude Code가 필수인가요?

필수는 아닙니다. Cursor만으로도 충분히 개발할 수 있습니다. 다만 "지시하고 결과를 검토하는" 방식이 편하다면 Claude Code가 잘 맞습니다. Claude Code는 Claude Pro 이상 유료 플랜에 포함됩니다.

### Obsidian과 Notion 둘 다 필요한가요?

역할을 나누면 둘 다 쓸 수 있습니다. Obsidian은 로컬 파일·버전 관리, Notion은 협업·데이터베이스에 강합니다. 혼자 작업한다면 Obsidian 하나로도 충분한 경우가 많습니다.

### 자동화로 놓치는 것은 없나요?

있습니다. 자동화 세팅에 매몰되면 정작 본업인 글쓰기나 개발을 못 합니다. "이달에 자동화는 1개만" 규칙을 두고, 자동화 결과는 주기적으로 직접 확인하세요.

### 추천 시작 순서는?

Apple 단축어 → Obsidian → Claude Code → Make 순서를 권합니다. 비용이 들지 않는 도구부터 시작해서 필요한 것만 추가하면, 쓰지 않는 구독이 쌓이지 않습니다.

### 번아웃 방지법이 있나요?

자동화의 목적은 "시간 벌기"이지 "더 많이 일하기"가 아닙니다. 작성자는 번 시간을 쉬는 데 쓰려고 취침 시간 규칙, 주말 하루 완전 오프, 분기 1회 휴식 주를 정해 두었습니다.

## 마무리

자동화 스택은 "내가 해야 할 진짜 일"만 남기는 필터다. 1인 개발자에게 시간은 가장 비싼 자원이고, 반복 작업은 가장 큰 누수다. 이 글은 분기 1회 갱신해 실제로 쓰는 도구만 남기도록 한다 — 새로 추가되거나 빠지는 도구가 있으면 `updated` 필드로 반영된다.
