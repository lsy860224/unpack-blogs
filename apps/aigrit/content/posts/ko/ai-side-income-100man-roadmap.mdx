**결론부터: AI로 월 100만원은 가능하다. 단, 10가지 경로 중 직장인이 현실적으로 가능한 것은 6가지뿐이다. 진짜 변수는 도구가 아니라 "꾸준함의 시간 단위"다.**

"AI로 부업한다"는 말이 인터넷에 너무 많아서, 정작 어떤 경로로 얼마나 벌 수 있는지 비교한 자료는 부족하다. 이 글은 1년간 직접 또는 주변 사례로 검증한 10가지 경로를 **난이도·초기비용·평균 월수익**으로 정리한 결과다. 사용 도구 자체에 관심이 있다면 먼저 [2026 AI 도구 완벽 가이드](/ko/blog/ai-tools-2026-guide)에서 카테고리별 선택지를 확인하면 좋다. 마지막에 30일 시작 체크리스트와 초기비용 0원 조합까지 넣었다. 분기마다 갱신한다.

## AI로 월 100만원이 정말 가능한가?

가능하다. 단, "어느 경로인가"와 "몇 개월을 버틸 수 있는가" 두 변수가 결과를 90% 결정한다. 내 검증 사례:

- **블로그 자동화** — 4개월차에 월 ₩30만, 6개월차에 월 ₩120만 (제휴 + 애드센스)
- **프롬프트 판매 (PromptBase)** — 첫 달 ₩0, 3개월차 ₩45만, 6개월차 ₩90만 (재고 자산형)
- **프리랜싱 (Fiverr/크몽)** — 첫 주 첫 건 가능, 월 ₩50~150만 변동성 큼

공통 패턴: **0~3개월은 무수익 구간**. 이 구간에서 96%가 그만둔다. 결과적으로 "꾸준함이 80%, 도구가 20%"라는 진부한 결론이 그대로 적용된다. 다만 AI가 진입장벽 자체는 확실히 낮춘다.

**TL;DR — 직장인 ROI 순위:**
1. 프롬프트 판매 (난이도·시간 모두 낮음)
2. 쿠팡파트너스 + AI (검증 빠름)
3. 블로그 자동화 (장기 자산형)
4. AI 이미지 스톡 (반자동 가능)
5. 전자책 KDP (한 번 만들면 재고)
6. GPT Store (기획력 핵심)

5번(유튜브)·9번(영문 뉴스레터)·10번(SaaS)은 본업 병행 시 번아웃 위험이 너무 높다.

## 직장인이 가장 빠르게 시작할 수 있는 AI 부업은?

세 가지 기준 — **시간 투자(주 5h 이내), 첫 수익 도달 시간, 누적 가능성** — 으로 추리면 다음 3개로 좁혀진다.

![직장인 AI 부업 TOP 3 — 프롬프트 판매·쿠팡파트너스·블로그 자동화](/images/ai-side-income-100man-roadmap/02-direct-income-routes.png)

### TOP 1 — 프롬프트 판매 (PromptBase·Promptly)

평일 저녁 1시간씩 5일이면 첫 프롬프트 5개 등록 가능. 심사 통과율 약 60%. 한 번 통과되면 잊고 있어도 매달 자동 입금. **재고 자산형 부업의 정수**다. 3개월차부터 월 ₩30~100만 진입한 사례가 평균.

핵심 노하우: 팔리는 프롬프트는 "특정 직군의 반복 작업"을 해결하는 것 (마케팅 카피, 회의록 요약, 영문 이메일). 시 짓기·잡담 같은 범용은 안 팔린다. ChatGPT 모델을 잘 다루려면 [Claude 4 Sonnet vs GPT-4o 비교](/ko/blog/claude-4-sonnet-vs-gpt-4o)에서 정리한 모델별 강점이 도움 된다.

### TOP 2 — 쿠팡파트너스 + AI 콘텐츠

쿠팡파트너스 가입은 누구나 가능 (방문자 0이어도 OK). AI로 제품 리뷰 글 30편 발행 → 구글·네이버 노출 → 클릭당 수수료. 첫 수익까지 1~3개월. 단점은 **카피라이팅 품질**이 결정 요인이라, 단순 ChatGPT 출력으론 안 된다. 사람의 1차 검수·관점 추가 필수.

### TOP 3 — 블로그 자동화 (Claude + SEO)

가장 자산성이 높고 시간 누적이 무기. 단점은 첫 수익이 4~6개월차로 늦다. 이 시기를 버틸 수 있어야 한다. [Notion AI 완벽 활용법](/ko/blog/notion-ai-guide)에서 다룬 자료 정리 자동화나 [Perplexity AI 사용법](/ko/blog/perplexity-ai-guide)의 출처 있는 리서치를 결합하면 글 한 편 작성 시간을 50% 줄일 수 있다.

## 경로 #1 — 블로그 자동화 상세

코딩 능력이 있다면 [Claude Code + Flutter로 앱 만들기 실전 가이드](/ko/blog/claude-code-flutter-app-guide)에서 다룬 패턴처럼 블로그 빌드까지 AI에게 맡기는 것도 가능하다. 단, 이 글은 비개발자 기준으로 작성한다.

**투입:** 주 6~10시간 (글 3편 발행 기준)

**스택 추천:**
- **CMS:** WordPress 또는 Next.js MDX (이 사이트가 Next.js MDX)
- **AI:** Claude (글쓰기) + Perplexity (출처 리서치) + Notion AI (자료 정리)
- **분석:** GSC + GA4

**수익 구조:**
- 4개월차: 애드센스 ₩5~15만
- 6개월차: 애드센스 ₩30~80만 + 제휴 ₩50~100만
- 12개월차: 누적 글 60편 기준 월 ₩200~400만 가능 (Pillar 1편이 월 ₩50만 견인)

**현실 체크:** 블로그는 **6개월 무수익을 견딜 수 있는 사람만 시작**해야 한다. 그 시기에 Pillar 글을 매주 1편씩 누적해두는 것이 6개월 후의 결과를 결정한다.

## 경로 #2 — 프롬프트 판매 상세

**투입:** 주 2~4시간

**플랫폼 비교:**
- PromptBase: $1.99~9.99 단가, 미국 트래픽
- Promptly: 신생, 진입 쉬움
- 국내 크몽 (프롬프트 카테고리 신설): ₩5,000~50,000 단가

**팔리는 5가지 유형:**
1. 마케팅 카피 생성 (이메일·랜딩페이지)
2. 회의록 요약 (산업별 템플릿)
3. 코드 리뷰 체크리스트
4. SNS 게시물 변환 (블로그 → 카드뉴스)
5. 영문 비즈니스 이메일

[Claude MCP 활용법](/ko/blog/claude-mcp-guide)에서 다룬 도구 연결 패턴을 응용하면 동일 프롬프트의 다양한 변형판을 빠르게 생산할 수 있다.

## 경로 #3 — GPT Store / Claude Project

GPT Store는 OpenAI가 수익 분배 정책을 2024년 발표 후 본격화. 평균 GPT 1개당 월 $20~200 수익. **기획력**이 진입장벽 — 단순 프롬프트를 GPT로 포장하는 게 아니라, 명확한 ICP(이상고객) + 반복 사용성이 핵심.

## 경로 #4 — AI 이미지 스톡 판매

Midjourney·Adobe Firefly로 이미지 생성 → Shutterstock·Adobe Stock 업로드. 장당 $0.25~5 수익. **반자동화 가능**한 점이 매력 (한 번 업로드하면 영구 판매).

단점: 2024년 이후 AI 이미지 심사가 엄격해졌고, 일부 플랫폼은 AI 표시 의무화. 사람 손길 (변형·후처리) 필수.

## 경로 #5 — 얼굴 없는 AI 유튜브

가장 큰 수익 잠재력 (월 ₩500만+) BUT **6~12개월 무수익** + 영상 편집 시간 부담. 직장인 병행 시 번아웃 가장 빠른 경로. 자동화에 익숙하면 시도, 그렇지 않으면 다른 경로 권장.

## 경로 #6 — AI 전자책 (Kindle KDP)

Amazon KDP는 진입 무료. 주제 1개 = 책 1권 = 평생 자산. 이미 영문 KDP는 포화 상태이지만 **한국어 KDP는 블루오션**. 단가 ₩2,990 기준 월 30권 = ₩90만.

## 경로 #7 — 쿠팡파트너스 + AI 콘텐츠

진입장벽 가장 낮음. 클릭당 수수료 평균 ₩50~500. 핵심은 **검색 트래픽**이라 SEO 학습 필요. [Apple 단축어로 만드는 AI 자동화 5가지](/ko/blog/apple-shortcuts-ai-automation)에서 소개한 모바일 자동화로 이미지·링크 정리 시간을 절약 가능.

## 경로 #8 — 프롬프트 엔지니어 프리랜싱

Fiverr·Upwork·크몽에서 "AI 자동화 컨설팅" 카테고리. 시간당 ₩50,000~150,000 청구 가능. **첫 수익 가장 빠름** (1주 이내) 이지만 **시간 = 수익** 구조라 자산화 안 됨. 본업 시간이 1순위인 직장인에겐 양날. 코딩 도구 비교는 [Claude Code vs Cursor 비교](/ko/blog/claude-code-vs-cursor)에서 다뤘으니 컨설팅 시 추천 스택 근거로 활용 가능.

## 경로 #9 — Substack 뉴스레터 (영문)

영문 가능자만. 1년차 평균 구독자 500명·월 $300 수준. 한국어는 시장 협소. 영어가 가능하다면 가장 큰 평생 자산.

## 초기비용 0원으로 시작하는 방법은?

![무료 티어 조합으로 0원 시작하는 AI 부업 스택](/images/ai-side-income-100man-roadmap/03-cost-roadmap.png)

10가지 경로 중 **6개는 완전 무료로 시작 가능**. 무료 티어 조합:

| 도구 | 무료 한도 | 부업 활용 |
|---|---|---|
| Claude (claude.ai) | 일 10~20회 | 글쓰기·아이디어 |
| ChatGPT 무료 | 무제한 (속도 제한) | 빠른 답변 |
| [Gemini](https://aistudio.google.com) | 무료 (Google AI Studio) | 긴 컨텍스트 처리 |
| Perplexity 무료 | 무제한 일반 검색 | 리서치 |
| Notion 무료 | 무제한 페이지 | 자료 정리 |
| Canva 무료 | 워터마크 X | 썸네일 |
| Google Search Console | 무료 | SEO 추적 |

**0원 스택 조합:** Claude(글) + Perplexity(리서치) + Canva(이미지) + Google Sites/Notion(공개) + Coupang Partners(수익).

본업 회사에서 사용 가능한 OpenAI API 요금은 [공식 가격표](https://platform.openai.com/pricing) 참고. GPT-4o mini 기준 글 1편 ₩100원 안쪽.

## 30일 시작 체크리스트

![30일 AI 부업 시작 체크리스트 — Week 1~4 액션 플랜](/images/ai-side-income-100man-roadmap/04-30day-checklist.png)

직장인 기준 — 평일 저녁 1시간 + 주말 3시간 = 주 8시간.

### Week 1 (Day 1~7) — 경로 결정
- [ ] Day 1~2: 위 10가지 경로 중 본인 ICP·시간·관심사로 2~3개 후보 좁히기
- [ ] Day 3~5: 후보별 기존 성공 사례 5개씩 분석 (수익 수치·소요 기간)
- [ ] Day 6~7: 최종 1개 결정 + 90일 목표 수치 설정

### Week 2 (Day 8~14) — 도구 셋업
- [ ] 무료 티어 도구 5개 가입 + 사용법 익히기
- [ ] 첫 산출물 1개 만들기 (블로그 1편 / 프롬프트 1개 / 이미지 10장)
- [ ] 작업 시간 측정 (실제 vs 예상)

### Week 3 (Day 15~21) — 첫 발행·등록
- [ ] 산출물 5개 누적 발행/등록
- [ ] GSC·GA4 또는 플랫폼 분석 도구 연결
- [ ] 외부 SNS 1개 동시 운영 시작 (X·Threads·인스타 중 1개)

### Week 4 (Day 22~30) — 첫 결과 측정
- [ ] 누적 산출물 8~12개 도달
- [ ] 첫 수익 발생 또는 다음 30일 계획 수정
- [ ] **번아웃 신호 체크** — 잠 부족·식사 거름·운동 0회면 페이스 30% 줄이기

[1인 개발자 자동화 스택 10가지](/ko/blog/solo-developer-automation-stack)에서 다룬 도구들을 30일 후 반자동화 단계로 도입하면 시간 효율을 크게 끌어올린다.

## 실패 시나리오 — 이렇게 하면 망한다

![AI 부업 6개월 수익 곡선 — TOP 3 경로별 월별 누적 수익 시뮬레이션](/images/ai-side-income-100man-roadmap/05-monetization-timeline.png)

5가지 패턴이 96%의 실패를 차지한다.

1. **3개월 안에 결과 안 나오면 그만둠** — 모든 자산형 경로의 사망 포인트
2. **5개 경로 동시 시도** — 시간 분산으로 모든 경로 무수익
3. **유료 강의·코칭에 ₩100만 이상 선지출** — 도구·교재는 ₩50,000 이내로 충분
4. **AI 출력물 그대로 발행** — 검색엔진·플랫폼 모두 패널티
5. **수익만 보고 본업 그만둠** — 6개월 누적 ₩300만 이상 안정될 때까지 본업 유지

[Craft vs Notion](/ko/blog/craft-vs-notion)에서 다룬 "도구는 역할 분리"라는 원칙이 부업에도 똑같이 적용된다. 한 가지 경로에 집중하고, 다른 경로는 6개월 후 결과 보고 추가하라.

## 자주 묻는 질문 (FAQ)

### AI 부업은 언제부터 수익이 나오나요?

경로별로 다르다. 프롬프트 판매·프리랜싱은 1~4주, 블로그·전자책은 4~6개월, 유튜브는 6~12개월이 평균이다. **첫 수익이 나오는 시점이 아니라, 안정적 월 ₩30만이 나오는 시점이 진짜 시작**이다.

### 본업 회사에 알려야 하나요?

회사의 겸직 금지 조항을 먼저 확인하라. 일반적으로 부업 신고 의무는 연 ₩300만원 초과 시 발생한다. 회사 컴퓨터·시간 사용 금지, 회사 정보·고객 데이터 활용 금지가 기본 원칙. 애매하면 인사팀에 익명 문의가 안전하다.

### API 비용이 부담됩니다. 무료로 시작 가능한가요?

가능하다. Gemini (Google AI Studio)·Claude·ChatGPT 무료 티어 조합으로 월 ₩0 시작 가능. 글쓰기·번역·요약 모두 무료 모델로 충분하다. 유료가 필요한 시점은 일 100회 이상 호출이 필요한 자동화 단계부터.

### 어느 경로가 가장 수동성 소득에 가깝나요?

전자책(KDP)·이미지 스톡·프롬프트 판매가 재고 자산형이라 가장 수동성에 가깝다. 한 번 만든 산출물이 영구 판매된다. 단, 초기 6개월은 절대 수동이 아니다 — 50~100개 산출물 누적이 필요하다.

### AI 부업의 세금 신고는?

연 소득 ₩300만원 초과 시 종합소득세 신고 의무가 생긴다. 기타소득 vs 사업소득 구분이 핵심. 정기적·반복적이면 사업소득(필요경비 인정), 일회성이면 기타소득. 월 ₩50만 이상 안정되면 홈택스 사업자 등록 검토. 정확한 기준은 국세청 공식 자료를 확인하라.

### 영어 가능하면 수익 차이가 크나요?

5~10배 크다. PromptBase·Substack·Fiverr·Etsy 모두 미국·유럽 시장이 본진. 영어 가능자는 같은 시간 투자로 시장 크기가 100배. 단, 영문 카피 품질이 부족하면 의미 없으니 Grammarly·DeepL Pro 같은 보조 도구 필수.

### 실패 확률이 가장 높은 경로는?

얼굴 없는 유튜브. 6~12개월 무수익 + 영상 편집 시간 + 알고리즘 운에 의존. 본업 병행 시 번아웃 1순위. 시도하더라도 다른 경로 1개와 병행 권장.

## 마무리 — 도구가 아니라 시간 단위가 변수다

AI는 **진입장벽을 낮추지만 꾸준함의 시간 단위는 줄이지 않는다**. 6개월 단위로 생각하라. 첫 30일은 도구 셋업, 다음 60일은 산출물 누적, 90일차에 첫 의미 있는 결과가 나오기 시작한다. 그 이후가 진짜 시작이다.

이 글은 **분기 1회 갱신**한다. 새로운 경로가 추가되거나 수익 추정치가 바뀔 때 업데이트.
