**결론부터: Apple 단축어에 AI API를 연결하면 요약·번역·음성 메모 저장 같은 반복 작업이 공유 시트나 단축키 한 번으로 끝난다. API 키 없이 시작하는 방법도 있다.**

아이폰과 맥을 쓴다면 이미 가장 강력한 자동화 도구를 가지고 있다. Apple 단축어다. 여기에 AI를 연결하면 "스크린샷 찍고 설명 붙이기", "음성 메모를 텍스트로 저장", "클립보드 번역" 같은 일이 터치 한 번으로 끝난다.

작성자가 직접 만들어 쓰는 단축어 5개를 공유한다. 구조가 같아서 하나를 만들면 나머지는 응용이다.

## Apple 단축어로 AI를 어떻게 쓸 수 있을까?

단축어 앱은 HTTP 요청을 보낼 수 있다. Anthropic Messages API든, OpenAI Chat Completions든 REST 엔드포인트가 있으면 연결 가능하다. API 키를 단축어 변수에 저장하고, "텍스트" 액션으로 프롬프트를 만들고, "URL 내용 가져오기"로 요청을 보낸다.

## 단축어 #1 — 선택 텍스트 한 줄 요약

아무 앱에서 텍스트를 선택하고 공유 시트에서 "한 줄 요약"을 누르면 Claude API가 50자 이내 요약을 반환한다.

**구성:**

1. 공유 시트에서 텍스트 입력 받기
2. 프롬프트: "다음 텍스트를 한국어 50자 이내로 요약해줘: {입력}"
3. Anthropic Messages API POST 요청
4. 결과를 클립보드에 복사 + 알림 표시

## 단축어 #2 — 스크린샷 → AI 설명 (블로그캡처 응용)

블로그에 스크린샷 넣을 때마다 alt 텍스트와 캡션을 쓰는 건 귀찮다. 이 단축어는 스크린샷을 찍으면 AI가 자동으로 alt 텍스트와 캡션을 생성하고, 지정 폴더에 저장한다.

**실전 팁:** AI가 만든 alt 텍스트는 사실과 다를 수 있으니 발행 전 한 번 읽고 고치자. 블로그 작업 전체를 자동화하는 흐름은 <Link href="/ko/blog/claude-blog-workflow-seo">Claude로 블로그 글쓰기·발행·SEO</Link>에서 다뤘다.

## 단축어 #3 — 음성 → Notion 자동 저장

걸으면서 떠오르는 아이디어를 음성으로 말하면 OpenAI 음성 인식 API가 텍스트로 바꾸고, Notion API로 데이터베이스에 저장한다.

**3단계 체인:**

```
단축어 오디오 녹음
  ↓
OpenAI 음성 인식 API (한국어 지원)
  ↓
Notion Pages API (데이터베이스 신규 항목 생성)
```

Notion Integration 토큰을 발급받고, 대상 데이터베이스를 Integration에 연결하면 된다.

**쓰임새:** 검색·태그가 되는 데이터베이스에 메모가 바로 쌓인다는 점이 핵심이다. Notion에서 AI를 더 쓰는 방법은 <Link href="/ko/blog/notion-ai-guide">Notion AI 활용법</Link>에 정리했다. 저장 위치는 Obsidian이나 Craft로 바꿔도 구조는 같다.

## API 키 없이도 AI 단축어를 만들 수 있을까?

**가능하다.** 대표적인 방법은 두 가지다.

1. **"모델 사용" 동작 (iOS 26·macOS 26):** Apple Intelligence를 지원하는 기기에서는 단축어에 Apple의 기기 내 모델, Private Cloud Compute, ChatGPT 중 하나를 골라 프롬프트를 보내는 동작을 쓸 수 있다. API 키가 필요 없다.
2. **ChatGPT 앱 동작:** [ChatGPT iOS 앱](https://apps.apple.com/app/openai-chatgpt/id6448311069)이 설치되어 있으면 앱이 제공하는 단축어 동작으로 질문을 보낼 수 있다.

| 방식 | 비용 | 모델 선택 | 준비물 |
| --- | --- | --- | --- |
| API 키 (Anthropic·OpenAI) | 사용한 토큰만큼 | 자유롭게 지정 | API 키, HTTP 요청 구성 |
| "모델 사용" 동작 | 추가 비용 없음 (ChatGPT는 계정 조건 따름) | Apple 모델·ChatGPT | Apple Intelligence 지원 기기 |
| ChatGPT 앱 동작 | 무료·유료 플랜 | 앱 설정 따름 | ChatGPT 앱 |

처음이라면 API 키 없이 "모델 사용" 동작으로 한두 개 만들어 보고, 모델이나 응답 형식을 세밀하게 정하고 싶어지면 API 키 방식으로 옮기는 순서가 무난하다.

## 자주 묻는 질문 (FAQ)

### OpenAI API는 유료인가요?

사용한 토큰만큼 과금되는 종량제입니다. Anthropic API도 같은 구조입니다. 비용은 모델과 사용량에 따라 크게 달라지므로, 콘솔에서 월 사용 한도를 설정해 두면 예상치 못한 과금을 막을 수 있습니다.

### iPad에서도 동일하게 작동하나요?

네. 단축어는 같은 Apple 계정의 iPhone·iPad·Mac 사이에서 iCloud로 동기화됩니다. Mac에서는 키보드 단축키 할당 같은 기능이 더해져 오히려 편한 경우도 많습니다. 다만 기기에서 지원하지 않는 동작은 실행되지 않습니다.

### Siri로 실행 가능한가요?

가능합니다. 단축어 이름을 "블로그캡처"로 지으면 Siri에게 그 이름을 말해 실행할 수 있습니다. 다만 텍스트 선택처럼 복잡한 입력이 필요한 단축어는 공유 시트나 단축키로 실행하는 편이 편합니다.

### Android에서 대안은?

Tasker 같은 자동화 앱이 가장 가까운 대안입니다. Make·Zapier처럼 웹훅으로 시작하는 자동화 도구를 쓰는 방법도 있습니다. 자동화 도구 사용법은 Make 자동화 가이드에서 다뤘습니다.

### 단축어를 다른 사람에게 공유할 수 있나요?

가능합니다. 단축어 공유 메뉴에서 iCloud 링크를 만들 수 있습니다. 다만 단축어 안에 API 키를 텍스트로 넣어 두었다면 링크에 함께 포함될 수 있으니, 공유 전에 키를 지우거나 "가져오기 질문"으로 받는 사람이 직접 입력하게 바꾸세요.

## 마무리

Apple 단축어는 "노코드 AI 자동화"의 가장 현실적인 진입점이다. Make·n8n 같은 본격 도구로 가기 전에, 손에 있는 아이폰·맥으로 먼저 시작해 보자. 가장 자주 하는 작업 하나부터 만들면 된다.
